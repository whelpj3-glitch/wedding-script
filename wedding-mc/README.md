# 웨딩 MC 큐카드

결혼식 사회자용 대본 앱. `index.html` 하나로 동작합니다(설치·빌드 없음).

- **대본 불러오기**: PDF(표 형식 `식순 | 사회자 멘트 | 참고` 포함) · TXT · 붙여넣기 → 식순별 자동 분리
- **편집**: 순서 이름/메모/담당(사회자·주례자)/BGM 메모/음악/대본. 순서 추가·삭제·이동·복제·나누기·합치기
  - 대본 표기: `(지시문)` · `*입장곡 ON*` 음향 큐 · `~자유 소개~` 애드리브 · `…!` 구호 · 빈 줄 = 문단
- **음악**: mp3 등 추가 → BGM 메모와 파일 이름으로 순서에 자동 연결 (파일은 이 기기 브라우저에만 저장)
- **타이밍(노래방 모드)**: 문장(여러 개도 가능)을 고르고 시작·끝 초 입력, 또는 음악을 틀고 `누른 채로 읽기`로 기록.
  재생하면 해당 초에 맞춰 글자가 차례로 채워지고, 시작 3초 전 카운트다운 표시. 음악 없는 순서는 스톱워치 기준
- **무대 모드**: 큰 글씨, 다음 순서 미리보기, 현재 시각/예식까지 남은 시간, 화면 꺼짐 방지,
  키보드·페이지 터너(↓/PageDown 다음 문장, ←/→ 순서 이동, Enter 음악 재생), 좌우 스와이프
- **큐시트**: 전체 흐름·음악·큐·예상 멘트 시간, 원본 식순표
- **설정/백업**: 글자 크기, 읽기 속도, 테마, 예식 일시(D-day), JSON 백업으로 기기 간 이동
